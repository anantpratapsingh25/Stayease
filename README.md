# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/stayease.git
```

Move into project

```bash
cd stayease
```

Install Dependencies

```bash
npm install
```

Create .env

```env
ATLASDB_URL=
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_KEY=
CLOUDINARY_SECRET=
MAP_TOKEN=
SECRET=
```

Start Server

```bash
node app.js
```

Visit

```
http://localhost:8080
```
